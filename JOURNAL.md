## 4. Как работает цикл

`resume_after_works.py`:

1. `ready()` — будит телефон, снимает keyguard, запускает AdvertApp,
   проверяет «технические работы».
2. Дедлайн: `start.replace(hour=8, minute=30)`; если уже прошёл —
   `start + 1 час`. (При старте 15:31 дедлайн 16:31.)
3. Читает `panel_settings.json` → `cycle`:
   `new_minutes` (12), `active_minutes` (25), `sleep_seconds` (30),
   `active_first` (True).
4. Если `active_first` — сначала `tasks.py --until <now+active_minutes>`,
   затем `hunter2.run(...)` на `new_minutes`. Иначе наоборот.
5. После каждой фазы проверяет маркер `offer.pending`: если появился —
   удаляет и сразу запускает «Активные» без паузы.
6. Пауза `sleep_seconds`, повтор до дедлайна или `hunter.stop`.

### Стратегия «Новые» (`hunter2.py`)

- Только **верхний экран**, без свайпов и без второй страницы.
- Если RU нет — **2 дополнительные перепроверки по 10 с**, затем выход.
- Сортировка заданий по цене (дорогие первыми).
- `idle_stop_minutes` — простой до выхода (по умолчанию 8).
- Модалки: `uninstall`, `not_enough_time`, `reminder`, `offer`,
  `instructions` (см. раздел 6).

### Стратегия «Активные» (`tasks.py`)

- Все страницы, стоп после **2 пустых экранов**, жёсткий предел 25 экранов.
- Сортировка по цене.
- `retry_count` — повторы на заказ.
- Если карточка у нижнего края (`top >= 1900`) — до 3 свайпов вверх и
  повторный поиск (`locate`), иначе тап попадает в нижнюю навигацию.

## 6. Модалки AdvertApp (важно)

| Тип | Признак | Действие |
|---|---|---|
| `uninstall` | «удалит … приложение «…»» | `pm uninstall`, подтвердить зелёной кнопкой, запомнить `LAST_UNINSTALLED_PKG`. |
| `not_enough_time` | «Вы не пробыли N секунд / Повторите выполнение» | взять `LAST_HELD_PKG`, закрыть, запустить `monkey`, держать `max(hold_min, N+5)`. |
| `reminder` | «Открыть приложение заказа … и провести N секунд» | зелёная «Открыть», запустить приложение, держать `max(hold_min, N+5)`. |
| `offer` | «Взять/новый заказ/предлагаем/доступен» или кнопка «Взять/Принять» | нажать зелёную, записать `offer.pending`, при напоминании сразу обработать. |
| `instructions` | «Поисковый запрос … Зайдите в Google Play … Открыть Google Play» | нажать зелёную, найти приложение в Play по запросу, установить, вернуться в AdvertApp, подтвердить, держать. |
| `other` | всё остальное | `response_status`; при неизвестном — безопасный BACK. |

Ключевые ошибки, уже исправленные:
- regex секунд не ловил `30 | секунд!` → `(\d+)\D{0,8}секунд`;
- regex номера заказа не ловил `Г\Р1395363` → `заказа\D{0,12}(\d{5,})`;
- OCR-заголовок заказа склеивался из двух строк → `merge_rows(tol=18)`;
- модалка-напоминание закрывалась BACK и висела → `accept_open_dialog`;
- модалка-инструкция закрывалась BACK → ветка `instructions`;
- Play-поиск открывал системный chooser («Открыть с помощью») → добавлен
  `-p com.android.vending`.
